Everything runs from this repository. Nothing here depends on Claude.

## Way 1: edit `content.txt` directly (works from your phone)

1. Open [`content.txt`](content.txt) and click the **pencil icon** (Edit).
2. Type next to each label, e.g. `title: The day we met`. Longer text goes on the lines under labels like `message:` or `letter:`.
3. Press **Commit changes**. The page updates about a minute later.

**Photos:** open the [`images`](images) folder → **Add file → Upload files** → choose photos → **Commit changes**.
Then, in `content.txt`, write the file name exactly as it is spelled, e.g. `photo: IMG_2041.jpg` (capital letters matter).

**Song (optional):** upload an MP3 to the [`music`](music) folder the same way, then set `music: song-name.mp3` in `content.txt`.

## Way 2: use the editor page

1. Open the **editor** link above. It has the same form as before: names, daily envelopes, memories, cake, letter and music. Tap **Preview** to see any day.
2. Go to the **Publish** tab → **Download update**.
3. Unzip it. Then on GitHub: **Add file → Upload files** → drag in `content.txt` and the `images` (and `music`) folder → **Commit changes**.

Only changed some words? In the Publish tab, tap **Copy content.txt text**, open `content.txt` on GitHub, select all, paste, commit.

The editor keeps your draft in the browser you used. If you change `content.txt` directly in between, it will ask which version to keep.

## Good to know

- **Unlocking:** each envelope opens at midnight on its day, by the date on her device. The birthday page (photo, cake, memories, letter) opens on **November 19**.
- **Photos:** use JPG or PNG. iPhone HEIC photos don't show on most phones. Choosing them through the editor on an iPhone converts them. The editor also shrinks photos, so the page loads faster.
- **Privacy:** this repository is public. Anyone who opens it can read `content.txt`, including envelopes that haven't opened yet. Don't put anything here you'd mind being public. You can delete the repository after her birthday.
- **Not updating?** GitHub can take a minute or two. Reload the page.
